Ruční stažení dat z RAWG

Záložní možnost. Normálně data obnovuje GitHub sám každé pondělí (Actions → „Aktualizace dat z RAWG“). Tahle stránka udělá totéž v prohlížeči: stáhne populární a vycházející PC hry, rozpozná požadavky a připraví soubor games.js, který pak nahraješ do složky data. Klíč se nikam neukládá a posílá se jen do RAWG.

⚠️ RAWG dovoluje 20 000 dotazů měsíčně a GitHub jich každé pondělí spotřebuje asi 3 700. Ruční stažení spotřebuje stejně – používej ho jen výjimečně.
